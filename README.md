# GitCar

## Sobre o projeto
O GitCar é uma aplicação desenvolvida em Java para gerenciar veículos, permitindo cadastrar, editar, listar e excluir registros.

O projeto foi criado com o objetivo de praticar conceitos de backend, organização em camadas e integração com banco de dados relacional.

## Tecnologias utilizadas
- Java
- MySQL
- JDBC
- Padrão DAO

## Funcionalidades
- Cadastro de veículos
- Atualização de dados
- Remoção de registros
- Listagem de veículos
- Persistência em banco de dados

## Estrutura
O projeto está organizado em camadas para separar responsabilidades:
- Model
- DAO
- Controller
- View

## Objetivo
Aplicar conceitos de Programação Orientada a Objetos e desenvolver um CRUD completo com integração ao banco de dados.

## Como executar
1. Clonar o repositório
2. Criar o banco no MySQL
3. Configurar as credenciais de conexão
4. Executar o projeto
